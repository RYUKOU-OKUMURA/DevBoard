# DevBoard ブランドカラー & デザイン プロンプト

AIに渡すだけで、DevBoardのブランドカラーとデザインシステムを実装できるシンプルなプロンプト集です。

---

## ⚡ 超シンプル版（1行プロンプト）

```
DevBoardのブランドカラー（Red #E53935 / Purple #673AB7）をCSS変数とTailwindクラスで実装し、グラデーション背景のCTAボタンとホバー時にPurpleグローするカードを作成してください。250msトランジション、motion-reduce対応。
```

---

## 🎯 メインプロンプト（コピペ用）

```
DevBoardのブランドカラーとデザインシステムを実装してください。

【ブランドカラー】
- Red: #E53935 (ライト) / #FF6B68 (ダーク) - エネルギー、アクション
- Purple: #673AB7 (ライト) / #8B6FDB (ダーク) - プレミアム、信頼

【デザイン原則】
「落ち着き」と「驚き」のバランス: 80%は静か、触れた瞬間だけ魔法が起きる

【実装内容】
1. CSS変数: 各カラーのバリエーション（base, emphasis, soft, glow）+ グラデーション（Red→Purple）
2. Tailwind統合: bg-brand-purple, text-brand-red などで使用可能に
3. CTAボタン: グラデーション背景 + メタリックシマー（ホバー時）
4. カード: ホバー時にグラデーションアクセントバー + Purpleグロー
5. トランジション: 250ms、motion-reduce対応

すべてのカラーはCSS変数から参照し、ライト/ダークモードに対応してください。
```

## 🎨 コンポーネント別プロンプト

### CTAボタン
```
グラデーションボタンを作成してください。
背景: Red→Purpleグラデーション、ホバー: シマーエフェクト、タップ: スケールダウン
```

### カード
```
カードにブランドカラーを適用してください。
ホバー: 上部グラデーションアクセントバー + Purpleグロー、Active: Redアクセント
```

### テキスト
```
重要見出しにグラデーションテキストを適用してください。
Red→Purpleグラデーション、パルスアニメーション（3秒）、motion-reduce対応
```

---

## 📐 デザイン原則（簡易版）

1. **カラー**: Purple（メイン）、Red（アクション）
2. **グラデーション**: Red → Purple（135度）
3. **エフェクト**: メタリックシマー、グロー
4. **モーション**: 250ms（標準）、控えめで心地よい
