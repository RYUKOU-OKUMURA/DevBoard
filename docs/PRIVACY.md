# プライバシーポリシー

**最終更新**: 2025-10-24

GitHub Dashboard（以下「本サービス」）は、ユーザーのプライバシーを尊重し、個人情報を適切に保護することを重要視しています。本プライバシーポリシーは、本サービスがどのような情報を収集し、どのように利用・保護するかを説明します。

---

## 1. 収集する情報

### 1.1 GitHub OAuth 認証情報

本サービスは、GitHub OAuth Apps を通じて以下の情報を収集します：

- **GitHub ユーザー名** (login)
- **ユーザーID** (id)
- **アバター画像URL** (avatar_url)
- **アクセストークン** (GitHub API へのアクセスに使用)

### 1.2 GitHub リポジトリ情報

本サービスは、認証されたユーザーの GitHub リポジトリ情報を取得します：

- リポジトリ名、所有者、URL
- 最終更新日時、アーカイブ状態、公開/非公開ステータス
- 説明文、プログラミング言語、トピック

### 1.3 ローカルストレージ

以下の情報をブラウザのローカルストレージに保存します：

- **保存ビュー** (検索クエリ、ソート順序、作成日時)
- **カスタムリポジトリ** (ユーザーが手動で追加したリポジトリ)

---

## 2. 情報の利用目的

収集した情報は、以下の目的で利用されます：

### 2.1 サービス提供

- GitHub リポジトリの取得と表示
- ユーザー認証とセッション管理
- 保存ビュー機能の提供

### 2.2 セキュリティ

- 不正アクセスの防止
- CSRF 攻撃の防止
- セッションの安全な管理

---

## 3. 情報の保存方法と期間

### 3.1 アクセストークンの保存

GitHub から取得したアクセストークンは、以下の方法で安全に保存されます：

- **暗号化方式**: AES-256-GCM
- **保存場所**: Cloudflare KV (Workers KV Storage)
- **有効期限**: 30日間
- **アクセス制御**: サーバーサイドのみアクセス可能（フロントエンドには露出されません）

### 3.2 セッション情報

セッション情報は HTTP Cookie として保存されます：

- **Cookie名**: `session_id`
- **属性**: `HttpOnly`, `Secure`, `SameSite=Lax`
- **有効期限**: 30日間
- **保存場所**: ユーザーのブラウザ

### 3.3 ローカルストレージ

保存ビューとカスタムリポジトリは、ブラウザのローカルストレージに保存されます：

- **有効期限**: 無期限（ユーザーが削除するまで）
- **アクセス**: 同じブラウザからのみアクセス可能

## 4. 情報の共有

本サービスは、収集した情報を第三者と共有しません。ただし、以下の場合を除きます：

### 4.1 GitHub API

本サービスは、ユーザーのアクセストークンを使用して GitHub API にアクセスします。GitHub のプライバシーポリシーは以下を参照してください：

- [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement)

### 4.2 Cloudflare

本サービスは、Cloudflare Pages および Workers を使用してホスティングされています。Cloudflare のプライバシーポリシーは以下を参照してください：

- [Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/)

### 4.3 法的要請

法律により義務付けられている場合、または正当な法的手続きに応じて情報を開示する場合があります。

---

## 5. セキュリティ対策

本サービスは、以下のセキュリティ対策を実施しています：

### 5.1 トークン保護

- AES-256-GCM による暗号化
- サーバーサイドのみでアクセス可能
- フロントエンドには露出されない

### 5.2 Cookie 保護

- `HttpOnly` 属性: JavaScript からアクセス不可
- `Secure` 属性: HTTPS 接続のみ
- `SameSite=Lax` 属性: CSRF 攻撃の緩和

### 5.3 CSRF 対策

- OAuth state パラメータによる検証
- 5分間の有効期限

### 5.4 セキュリティヘッダー

- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Referrer-Policy: strict-origin-when-cross-origin`

## 6. ユーザーの権利

### 6.1 データへのアクセス

ユーザーは、本サービスが保存している自分のデータにアクセスする権利があります。

### 6.2 データの削除

ユーザーは、以下の方法でデータを削除できます：

- **セッションデータ**: ログアウトボタンをクリック
- **ローカルストレージ**: ブラウザの設定から削除
- **GitHub OAuth App の認証解除**: GitHub Settings → Applications → Authorized OAuth Apps から解除

### 6.3 アクセストークンの無効化

GitHub OAuth App の認証を解除することで、本サービスのアクセストークンを即座に無効化できます：

1. GitHub Settings にアクセス: https://github.com/settings/applications
2. "Authorized OAuth Apps" タブを選択
3. "GitHub Dashboard" を見つけて "Revoke" をクリック

---

## 7. データの保持期間

- **セッションデータ**: 30日間（または、ユーザーがログアウトするまで）
- **ローカルストレージ**: ユーザーが削除するまで無期限

30日間ログインがない場合、セッションは自動的に期限切れとなり、KV から削除されます。

---

## 8. Cookie の使用

本サービスは、セッション管理のために Cookie を使用します。Cookie を無効にすると、本サービスを利用できません。

### Cookie の種類

| Cookie名 | 目的 | 有効期限 | 種類 |
|---------|------|---------|------|
| `session_id` | ユーザー認証とセッション管理 | 30日間 | 必須 |

## 9. 未成年者のプライバシー

本サービスは、13歳未満の子供を対象としていません。13歳未満の子供の個人情報を意図的に収集することはありません。
